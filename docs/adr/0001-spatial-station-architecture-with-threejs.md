# 0001. Spatial Station Architecture with Three.js and Vite

The existing Jekyll static site is replaced with a custom Vite-powered Three.js application hosted on GitHub Pages. Instead of a traditional vertical document scroll, navigation travels the 3D camera between defined spatial stations (Gateway, Lab, Arsenal, Transmission). This decision enables realistic optical physics (specular reflections, chromatic aberration, lens flares) and 3D visual anchors while retaining accessible HTML/CSS content overlays and adaptive power throttling.
