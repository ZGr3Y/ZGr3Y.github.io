# Portfolio Context

Spatial 3D portfolio experience for Paolo Maria Scarlata (ZGr3Y), showcasing Web Security and engineering projects through a futuristic optics aesthetic.

## Language

**Station**:
A 3D coordinate waypoint and visual focal point representing a logical section of the portfolio (Gateway, Lab, Arsenal, Transmission).
_Avoid_: Page, screen, slide, view

**HUD**:
The persistent minimalist heads-up display floating over the 3D canvas that displays current coordinate status and allows instant station jumping.
_Avoid_: Navbar, header, menu

**Holographic Card**:
An interactive glassmorphic panel in Station Lab with refractive borders and specular flare responsiveness that presents a project.
_Avoid_: Card, box, widget

**Idle Damping**:
The performance throttling system that steps down the GPU render loop when the camera is static and no pointer interaction is detected.
_Avoid_: Sleep, pause, freeze
