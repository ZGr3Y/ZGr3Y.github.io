# Portfolio Context

Spatial 3D cloud-native portfolio experience for Paolo Maria Scarlata (ZGr3Y), showcasing Cloud Systems and Security Engineering through an interactive infrastructure topology aesthetic.

## Language

**Station**:
A 3D coordinate waypoint and visual focal point representing a logical tier of cloud infrastructure (Gateway, Lab, Arsenal, Transmission).
_Avoid_: Page, screen, slide, view

**HUD**:
The persistent minimalist heads-up display floating over the 3D canvas that displays current station status and allows instant tier navigation.
_Avoid_: Navbar, header, menu

**Cloud Mesh Topology**:
The interactive 3D cluster of computing nodes and data links reacting to mouse input with real-time spring physics and primary color signals.
_Avoid_: Abstract sculpture, crystal, prism

**Cloud Card**:
A soft elevated card on the ice-white canvas featuring subtle ambient shadows, crisp typography, and semantic primary color accents.
_Avoid_: Holographic panel, dark glass pane

**Idle Damping**:
The performance throttling system that steps down the GPU render loop when the camera is static and no pointer interaction is detected.
_Avoid_: Sleep, pause, freeze
